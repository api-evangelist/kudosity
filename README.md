# kudosity

Australian business messaging platform (formerly Burst SMS / TransmitSMS) running two live public REST APIs: Transmit Message (v2) for SMS, MMS, WhatsApp and RCS with API-managed webhooks, and Transmit SMS (v1) for contacts, lists, numbers, keywords and reporting. Both ship public OpenAPI. Layered on top is an unusually complete agent-native surface — a hosted MCP server with an anonymous `tools/list`, llms.txt on two hosts with per-section fan-out, and five open-source agent integrations (Claude Code, Copilot, Gemini CLI, OpenClaw, GitHub Action).
