# Kudosity

Business messaging platform for SMS, MMS, RCS and WhatsApp (formerly Burst SMS / TransmitSMS). Exposes two public REST APIs, OpenAPI contracts, a hosted MCP server, llms.txt files, and published agent plugins.

- **Provider:** https://kudosity.com
- **Documentation:** https://developers.kudosity.com/docs
- **Base URL:** https://api.transmitmessage.com
- **Tags:** Messaging, SMS, MMS, RCS, WhatsApp, Communications, CPaaS, Webhooks, MCP, Agent-native
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** yes
- **Confidence:** 98/100

## APIs

- **Transmit Message API** — Current v2 REST API covering SMS, MMS, RCS and Webhooks. Authenticated via x-api-key header. (`https://api.transmitmessage.com`)
- **Transmit SMS API** — Legacy/classic REST API for SMS. Authenticated via HTTP Basic Authentication (API key + secret). (`https://api.transmitsms.com`)

> Kudosity is both API-first and agent-native. Two public REST APIs with public OpenAPI 3.x specs, a hosted remote MCP server at https://developers.kudosity.com/mcp (connected via npx mcp-remote with Basic auth), two llms.txt files, and multiple published agent plugins (Claude Code, GitHub Copilot, Gemini CLI, OpenClaw, GitHub Action). No AsyncAPI, GraphQL, or public Postman collection found. MCP server is hosted/remote (public https domain) so cataloged as an MCP property.
